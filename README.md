# CraftSurvive live evidence

Captures and readouts retained for Den tasks in project `rusty-craftsurvive`. This orphan
branch holds evidence only; it shares no history with `main` and nothing builds from it. Each
directory is named for its task, and each task's Den thread says what the files show, on which
Engine pair and machine.

- `8894/`: streamed render-wgpu tool captures (1280x720) of the default world and the courtyard
  study, each with the `engine.renderer` readout (`skippedOps`, `lastSkip`) and
  `engine.renderer.presentation` taken right after the capture, plus the capture's response headers.
- `8895/`: a charge's dust and debris in flight, and the crater after.
- `8896/`: creatures placed through the world frame, from an observer camera, before and after
  a 2 km rebase.
